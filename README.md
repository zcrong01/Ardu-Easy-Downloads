# 아두쉽게(Ardu-Easy) 1.4 · 2026 베타

AI교육연구회의 Windows 10·11 64비트용 무료 코드 편집·검사·아두이노 업로드 도구입니다. 배포용 설치파일 이름은 `Ardu-Easy_v1.4_Setup.exe`입니다. Python이나 Arduino IDE를 별도로 설치할 필요가 없습니다.

1.4는 사용 준비·점검, USB 후보 연결·장치 재확인, 부품별 점검 코드, 준비 결과 요약을 개선한 UX008 바이너리에 붙인 사용자용 번호입니다. 자세한 사용법은 [USER_GUIDE.md](USER_GUIDE.md), 변경 사항과 검증 한계는 [RELEASE_NOTES.md](RELEASE_NOTES.md), 파일 지문은 [SHA256SUMS](SHA256SUMS)를 확인하세요.

설치 내부 버전과 Windows 앱 제거 목록의 버전은 **2026.10.15.8**입니다. 실행 앱에는 별도 PE 파일 버전 번호가 없으며 앱 화면에 1.4가 표시된다고 보장하지 않습니다. 내부 안내에는 UX008·로컬 검토 후보 문구가 남아 있습니다. 원래 바이너리를 재빌드하지 않고 제공하므로 생기는 표시 차이입니다.

**2026-12-31까지 사용 가능하며 2027-01-01부터 만료 안내가 표시됩니다.** 만료 화면의 업데이트하기는 AI교육연구회 홈페이지를 엽니다. 기간 연장이나 자동 업데이트를 포함하지 않습니다.

앱과 설치파일은 전자서명이 없습니다. Windows SmartScreen 또는 조직 정책이 경고하거나 차단할 수 있습니다. 배포처와 SHA256을 확인하고 조직 정책을 따르세요. 보안 설정을 해제하도록 요구하지 않습니다.

첫 코딩 도구 준비에는 인터넷이 필요합니다. CLI·보드 코어·라이브러리·USB 드라이버를 이 설치파일에 묶은 것은 아닙니다. 준비한 코딩 도구는 앱 전용 폴더에서 재사용하며 Arduino IDE와 별도입니다. 드라이버가 필요한 경우 앱의 점검과 별도 정상 Windows 승인을 따릅니다.

검증 결과는 소프트웨어 검사 범위에 한정됩니다. 이 1.4 후보의 실제 USB 보드 업로드·실제 UAC/드라이버 설치·새 설치본의 호스트 설치 및 별도 PC 동작은 미검증입니다. FTDI 공식 서버가 HTTP 403을 반환한 환경에서는 자동 다운로드를 완료하지 못했습니다.
