# 아두쉽게 (Ardu-Easy) Windows 다운로드

AI교육연구회가 제공하는 무료 Windows 설치 앱입니다. 설치 파일은 해당 버전 Release의 첨부 파일에서 내려받습니다. 아직 게시되지 않은 버전은 링크가 열리지 않을 수 있습니다.

- 버전: 2026.10.14.7
- 파일: Ardu-Easy_Setup.exe (9,705,059바이트, 약 9.7 MB)
- 지원: Windows 10/11 x64, 사용자별 설치. 관리자 권한·별도 Python 설치 불필요
- 안내: [AI교육연구회](https://aiers.kr/) · [위드석 606](https://withseok.tistory.com/606)
- [고정 버전 설치 파일](https://github.com/zcrong01/Ardu-Easy-Downloads/releases/download/ardu-easy-v2026.10.14.7/Ardu-Easy_Setup.exe)

디지털 서명되지 않은 파일(NotSigned)이므로 Windows SmartScreen 또는 기관 정책에 따라 경고나 설치 차단이 있을 수 있습니다. 기관 정책을 따르고 파일명·출처·체크섬을 확인하세요.

베타 사용 기한은 2026-12-31까지이며 2027-01-01부터 만료됩니다. AI교육연구회 홈에서 업데이트를 확인하세요. 처음 도구·보드를 준비할 때 인터넷이 필요하며 준비가 끝난 도구·보드는 오프라인에서 사용할 수 있습니다. 모든 보드·라이브러리 동작을 보장하지 않습니다.

[사용 안내](USER_GUIDE.md)와 [SHA256 체크섬](SHA256SUMS.txt)을 확인하세요. 소스코드·회원자료·개인 설정을 포함하지 않는 설치 파일 전용 배포입니다.
